导入 robin 凭证 oauth_token → master token

从浏览器里取出 oauth_token Cookie（值形如 oauth2_4/…），粘贴到这里。 服务端会用 gpsoauth 换成长期 master token，再 mint 出访问令牌。master token 长期有效，但如果之后修改 Google 密码，需要重新导入一次。

高级：Android 应用身份（app / client_sig）
默认 com.google.android.gms + 38918a45…。如果报 RESTRICTED_CLIENT，说明这组身份被 Google 限制，换一组即可——不用重新拿 oauth_token 的话，可以在下方凭证行点「改 app」重试。
导入时会立即验证一次 mint + project 查询
怎么拿 oauth_token？
oauth_token 只在 Android 设备添加账号（EmbeddedSetup） 流程里写入；普通的 accounts.google.com 网页登录不会产生这个 Cookie。
1. 用无痕窗口打开 Android 设备登录页。
2. 用目标账号登录，跟着页面走完（可能显示“添加账号到设备”，不需要真的连接设备）。
3. F12 → Application → Cookies → https://accounts.google.com，找 HttpOnly 的 oauth_token（值形如 oauth2_4/…，document.cookie 读不到），复制整段值。
4. 粘到上面的表单。它在换出 master token 后即失效；但 master token 等价账号权限，只导入到自己的实例。
已有 master token？直接导入（迁移 / 换部署）
master token 是 oauth_token 换出来的长期令牌（形如 aas_et/… 或 oauth2rt_/…）。 换了部署、或者 Render 重启清空 /data 之后，用它把凭证塞回去，不必再走一次登录页。
