导入 robin 凭证 oauth_token → master token

从浏览器里取出 oauth_token Cookie（值形如 oauth2_4/…），粘贴到这里。 服务端会用 gpsoauth 换成长期 master token，再 mint 出访问令牌；之后自动续期，不用再登录。

导入时会立即验证一次 mint + project 查询
怎么拿 oauth_token？
1. 浏览器打开 https://accounts.google.com 并登录目标账号。
2. F12 → Application/Application → Cookies → accounts.google.com，找名为 oauth_token 的 HttpOnly Cookie（document.cookie 读不到）。
3. 复制整段值。它在换出 master token 后即失效，无需担心泄露；但 master token 等价账号权限，请只在自己的机器上导入。
OAuth 授权导入 Antigravity 客户端流程

走标准 Google OAuth（与 Antigravity / Gemini CLI 相同的 client），拿到 refresh_token 后由服务端自动刷新。 适合不方便从浏览器抠 Cookie 的场景。

–

回调地址是本服务的 /admin/oauth/callback；授权完成后自动回到此页。若在无头环境，把链接发给能打开浏览器的设备即可。
